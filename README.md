# EasyR · 数据工作台

用按钮操作 R 的模块化数据工具。基于 Shiny，支持 CSV / Excel 导入、数据清洗、数据预览、描述统计、二维与 3D 绘图、线性回归、时间序列分析和结果导出。日常操作不需要编写代码。

## 启动

在 RStudio 中打开 `app.R`，点击 **Run App** 即可。应用默认使用电脑的系统浏览器打开；首次加入此设置后，如果当前 RStudio 已经打开，请先重启一次 R 会话，再点击 **Run App**。

页面右上角提供 **English／中文** 按钮，可以随时切换界面语言。切换不会刷新页面，也不会清除已经导入的数据、分析结果或当前设置；用户数据中的字段名和内容保持原样。

程序会自动检查依赖，首次启动时只安装缺少的包，完成后自动打开界面。请保持联网，并在 Console 中查看安装进度；后续启动会复用已安装的包。下载的依赖保存在项目内的 `.R-library/`，不会上传 GitHub。安装失败时会显示原因提示，解决后再次点击 **Run App** 即可。

如果偏好终端，也可以在项目目录执行：

```sh
Rscript -e 'print(source("app.R")$value)'
```

如需仅安装依赖，可以单独运行 `Rscript setup.R`。

## 使用

先在左侧“工作目录”点击“浏览文件夹”，通过“打开子文件夹”或“上一级”定位目标目录，点击“选择此文件夹”，再点击“确定工作目录”。也可以粘贴文件夹完整路径后确认。初始目录为项目文件夹；无效或不可写路径会提示错误并保留原目录。

“保存 CSV 到工作目录”和“保存 PNG 到工作目录”会直接保存结果，并显示完整保存路径。每次保存生成独立文件名，不覆盖已有文件。“下载”按钮使用浏览器自己的下载位置。

此设置仅对当前应用会话生效，重新启动后恢复项目目录。它是本应用的文件保存目录，不会修改 R 进程的 `getwd()`，因此不会影响模块加载或其他会话。当前版本用于本机运行，目录浏览的是运行 R 程序的电脑。

1. 选择单个文件上传上限（默认 500 MB，可选 100 MB 或 1000 MB），再点击“选择文件”。按住 Command（macOS）或 Ctrl（Windows）可一次选择多个 CSV；也可以在文件窗口中框选。
2. 批量 CSV 共用当前编码、分隔符和“第一行是字段名”设置。该选项默认勾选；取消后第一行会作为普通数据，程序自动生成字段名。Excel 同样支持此设置和工作表选择，但每次只导入一个 Excel 文件。
3. 点击“导入并加入数据集”。新文件会加入当前会话；遇到同名文件时自动添加编号并保留两份，不会无提示覆盖已有数据。
4. 使用页面顶部蓝色“当前数据集”状态栏切换文件。预览、清洗、绘图、线性回归和时间序列会一起切换到当前文件；“移除当前数据集”只从本次运行中移除，不会删除电脑上的原文件。
5. 在“字段概况”查看当前数据集的字段类型和缺失数。
6. 在左侧选择保留字段、缺失值处理方式，并按需删除重复行。每个数据集分别保存自己的清洗选项；切换回来会恢复此前设置。“恢复原始数据”只重置当前数据集。
7. 在“统计与绘图”使用 ggplot2 或 Plotly 绘图；展开“查看数值字段描述统计”可查看有效数、均值、中位数和标准差。
8. 点击“下载处理后的 CSV”或“下载 PNG 图片”保存当前数据集的结果。

### ggplot2 绘图

二维“统计与绘图”图形使用 ggplot2，交互式 3D 散点图使用 Plotly；缺少相关包时 Run App 会自动安装。选项修改后立即更新，无需编写代码。

| 图形 | 常用操作 |
| --- | --- |
| 直方图 | 调整 5～100 个分箱，一键显示均值／中位数竖线，按组着色或分面 |
| 密度图 | 显示均值／中位数竖线，按组叠加或分面 |
| 散点图 | 分组着色，添加线性回归线，开关 95% 均值置信带，调整点大小和透明度 |
| 3D 散点图 | 选择三个数值轴，拖动旋转、滚轮缩放、悬停查看数值，并按低类别字段着色 |
| 箱线图 | 按组比较，叠加原始数据点，横向显示 |
| 小提琴图 | 按组展示分布，内嵌箱线图，叠加原始数据点，横向显示 |
| 类别频数图 | 展示前 20 类及频数标签，横向显示 |

例如：选择直方图和一个数值字段，勾选“显示均值竖线”即可添加虚线；勾选“显示中位数竖线”可同时对照。下方表格显示参考数值，分组后各条线按各组实际绘图数据计算。

点击“编辑图像”按钮可展开设置，再次点击可收起。这里提供自定义标题、轴标签、三种主题、单组颜色、分组配色、透明度、点大小、线宽、字号，以及 PNG 宽高和 DPI。“恢复默认绘图设置”重置样式和图层开关，保留当前字段选择。预览和保存共用同一个 ggplot 对象；导出尺寸可独立设置，版面会随尺寸调整。

回归和时间序列中的每一张 ggplot2 图也有独立的“编辑图像”按钮。可以分别修改标题、副标题、坐标轴名称、主题、配色、背景、线宽、点大小、透明度和字号，并为每张图单独设置 PNG 宽高与 DPI。每张图都提供“下载 PNG”和“保存 PNG 到工作目录”；透明背景会保留到导出文件。3D 散点图使用 Plotly 工具栏编辑视角，并通过相机按钮导出当前视角。

“分组字段”只列出含 2～20 个有效类别的字段，并排除当前绘图数值字段，防止把连续价格、收益率等数值误当成几十或几百个组。低基数数值编码仍可作为分组，例如 0/1 或评级代码；选择后会按离散类别处理。选择“不分组”即可关闭分组。数据或坐标轴变化导致原分组不再适用时，程序也会自动恢复为“不分组”。分面最多 12 组；分组缺失的数据不参与绘图。

3D 散点图由 Plotly 交互式 WebGL 图形提供，X、Y、Z 必须是三个不同的数值字段。鼠标拖动可旋转，滚轮可缩放，悬停显示三个坐标及分组值，工具栏相机按钮可保存当前视角的 PNG。为避免大型金融数据拖慢或卡死浏览器，有效数据超过 50,000 行时会均匀抽取 50,000 个点用于显示，并在图下方说明；原始数据不会因此改变。

密度／小提琴图要求每组至少两个不同数值。回归线按组拟合，样本不足的组会跳过并提示；置信带不是单个观测值的预测区间。密度图每组独立归一化，不能按面积比较样本量。横向显示时，轴标题设置对应翻转前的原始映射。

图层依据：[ggplot2 官方文档](https://ggplot2.tidyverse.org/reference/)。

### 线性回归与专业解读

在“线性回归”页选择数值因变量 Y 和一个或多个自变量 X，点击“运行线性回归”。模型调用 R 的 `lm()`，默认包含截距，采用自变量相加的普通最小二乘模型。数值自变量保留原始单位；文字、逻辑和因子作为类别处理，以有效样本中排序后的第一类为参照。数值编码的类别目前会视为连续变量。

- “专业解读”：按统计报告结构说明模型设定、完整案例、R²、调整后 R²、残差标准误、AIC/BIC、整体 F 检验、VIF 共线性诊断，以及各项未标准化系数、标准化系数、标准误、t 值、p 值和 95% 置信区间；同时列出 OLS 推断前提与解释边界。
- “系数表”：估计值、标准误、t 值、双侧 p 值和 95% 置信区间。
- “拟合图（ggplot2）”：单一数值自变量时显示散点、`lm` 拟合线和平均响应的 95% 置信带；多自变量或包含类别变量时显示实际值与完整模型拟合值，避免把多元模型误画成未经控制的单变量直线。
- “诊断图（ggplot2）”：残差与拟合值图包含平滑趋势线，并提供残差正态 Q-Q 图。
- 拟合图、残差图和 Q-Q 图都可独立编辑样式，并分别下载或保存 PNG。
- 支持下载 TXT 专业解读报告，或直接保存到当前工作目录。

回归使用左侧清洗后的数据，只排除所选回归字段中的缺失值和非有限数值。修改数据或变量后会清除旧结果，需要重新运行。样本不足、常量字段、完全共线会给出提示；接近完美拟合会提醒检查数据泄漏。解读由本地规则根据实际计算结果生成，无需 AI 账号或网络服务，不向外发送数据。

解读描述统计关联，不能用于直接推断因果。常规推断依赖模型假设；没有纳入填补不确定性、稳健标准误、多重检验校正或样本外评估。当前不支持交互项、自定义公式、权重或新数据预测。

### 时间序列分析

在“时间序列”页选择时间字段与数值字段，然后点击“运行时间序列分析”。时间字段支持日期、日期时间、常见文字日期格式和数值序号；程序会按时间升序排列，并将同一时间的多个数值按均值合并。

- 序列变换：原始值、一阶差分、百分比变化和对数收益率。对数收益率要求原始值全部大于 0。
- 序列图：使用 ggplot2 绘制，可叠加 2～200 期向后移动平均、线性趋势或 LOESS 趋势。
- 自相关图：使用 ggplot2 显示 ACF 和白噪声近似 95% 界限；滞后单位为相邻观测。
- 季节分解：使用 STL 分离趋势、季节项和余项，再以 ggplot2 分面显示。月度数据周期通常为 12、季度为 4，交易日周周期可尝试 5，但周期应由数据含义决定。
- 分析摘要：报告有效时间点、排除行、重复时间、描述统计、线性时间趋势、ACF(1) 和时间间隔规则性。
- 序列图、ACF 图和 STL 分解图都可独立编辑样式，并分别下载或保存 PNG。

移动平均、ACF 和 STL 都按观测顺序计算。对于不规则日期，程序不会自动补齐缺失的日历日期；金融交易日中的周末缺口不会被视为额外观测。趋势、季节性和自相关描述统计结构，不自动建立因果关系，也不等同于样本外预测。

计算依据：[R 官方 lm 文档](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/lm.html)、[summary.lm](https://www.stat.ethz.ch/R-manual/R-devel/library/stats/html/summary.lm.html)、[confint](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/confint.html)。

清洗顺序为选择字段 → 处理缺失值 → 去除重复行。中位数填充仅针对有有限数值的数值字段，不填充文字字段或全空字段。数值图和描述统计忽略缺失值及无穷值；类别图显示频数最高的 20 类。CSV 使用 UTF-8 BOM，便于 Excel 打开；再次导入 CSV 时字段类型可能重新推断。

没有文件时，点击“试用示例”。CSV 第一行为列名；Excel 使用 readxl 的类型推断。导入失败会保留上一份成功的数据。上传文件不会被写入项目目录；Shiny 会使用临时上传文件。

批量上传传输层最多接受约 4 GB 的一次请求，界面中的 100／500／1000 MB 选项控制每个文件的应用限制。若文件已经上传但超过当前选择，可提高上限后再次点击“导入并加入数据集”，无需重新选择。所有数据集保存在当前 R 会话内，因此同时载入许多大型文件会累积占用内存。Excel 是压缩格式，读取后的内存占用常会明显大于磁盘文件；导入超过 200 MB 的文件时界面会提示，建议使用 64 位 R，并预留充足内存。

## 模块结构

- `app.R`：入口和模块连接。
- `R/import.R`：单文件与批量 CSV 读取、数据集集合、顶部切换栏及导入状态。
- `R/preview.R`：预览和字段概况。
- `R/workbench.R`：清洗及 CSV 导出。
- `R/plotting.R`：封装 ggplot2 图层、描述统计、绘图设置及 PNG 导出。
- `R/plot_editor.R`：所有分析模块共用的 ggplot2 标题、主题、配色、线型属性和 PNG 导出编辑器。
- `R/directory.R`：工作目录选择、路径验证和文件保存。
- `R/regression.R`：线性回归、系数解读、ggplot2 拟合及诊断图和报告导出。
- `R/timeseries.R`：时间解析、序列变换、移动平均、趋势、ACF、STL 分解及 ggplot2 图形。
- `R/i18n.R`：右上角中英文切换、界面文字翻译及动态内容同步。
- `setup.R`：启动时自动检查和安装依赖。

新增清洗、绘图或统计模块时，分别提供 `xxx_ui(id)` 和 `xxx_server(id, data)`；通过响应式数据连接模块，避免全局共享用户数据。

## GitHub 与在线使用

源码仓库：[Linklee-sad/EasyR](https://github.com/Linklee-sad/EasyR)（私有）。GitHub 用于保存代码、协作和版本管理；在线运行 Shiny 需要另行配置支持 R 的服务。GitHub Pages 无法直接运行本项目。

请勿将私人数据或凭据提交到仓库。公开发布前需确定仓库名称、账号和开源许可证。

开发方式：用自然语言描述需求 → 实现独立模块 → 使用示例和真实边界案例验证 → 提交改动。

参考：[Shiny 官方模块文档](https://shiny.posit.co/r/articles/improve/modules)。

## 验证

在项目根目录执行 `Rscript smoke_test.R`，检查批量 CSV 导入、数据集切换、Excel 导入、清洗边界、CSV 编码及基础图表导出。当前版本面向本地使用，尚未部署在线服务。

执行 `Rscript regression_test.R`，将回归结果与原生 `lm()` 对照，并验证类别变量解读、异常输入、旧结果清除和报告保存。

执行 `Rscript plotting_test.R`，验证六类 ggplot 图形、均值／中位数参考线位置、分组分面及 PNG 导出尺寸。

执行 `Rscript timeseries_test.R`，验证时间解析、重复时间合并、序列变换、移动平均、趋势、ACF、STL 分解和 PNG 保存。

执行 `Rscript plot_editor_test.R`，验证通用 ggplot2 图像编辑、主题、配色、线宽、点大小以及 PNG 导出尺寸。
