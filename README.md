# R Mod · 数据工作台

用按钮操作 R 的模块化数据工具。第一版基于 Shiny，支持 CSV / Excel 导入、数据预览和字段概况。界面使用中文，日常导入不需要编写代码。

## 启动

在 RStudio 中打开 `app.R`，点击 **Run App** 即可。

程序会自动检查依赖，首次启动时只安装缺少的包，完成后自动打开界面。请保持联网，并在 Console 中查看安装进度；后续启动会复用已安装的包。下载的依赖保存在项目内的 `.R-library/`，不会上传 GitHub。安装失败时会显示原因提示，解决后再次点击 **Run App** 即可。

如果偏好终端，也可以在项目目录执行：

```sh
Rscript -e 'print(source("app.R")$value)'
```

如需仅安装依赖，可以单独运行 `Rscript setup.R`。

## 使用

1. 点击“选择文件”，选择 CSV、XLS 或 XLSX（最大 30 MB）。
2. CSV 可选择编码和分隔符；Excel 可选择工作表。
3. 点击“导入数据”，在右侧搜索、排序和分页预览。
4. 在“字段概况”查看字段类型和缺失数。

没有文件时，点击“试用示例”。CSV 第一行为列名；Excel 使用 readxl 的类型推断。导入失败会保留上一份成功的数据。上传文件不会被写入项目目录；Shiny 会使用临时上传文件。

## 模块结构

- `app.R`：入口和模块连接。
- `R/import.R`：文件读取、导入界面及其状态。
- `R/preview.R`：预览和字段概况。
- `setup.R`：启动时自动检查和安装依赖。

新增清洗、绘图或统计模块时，分别提供 `xxx_ui(id)` 和 `xxx_server(id, data)`；通过响应式数据连接模块，避免全局共享用户数据。

## GitHub 与在线使用

源码仓库：[Linklee-sad/r-mod](https://github.com/Linklee-sad/r-mod)（私有）。GitHub 用于保存代码、协作和版本管理；在线运行 Shiny 需要另行配置支持 R 的服务。GitHub Pages 无法直接运行本项目。

请勿将私人数据或凭据提交到仓库。公开发布前需确定仓库名称、账号和开源许可证。

开发方式：用自然语言描述需求 → 实现独立模块 → 使用示例和真实边界案例验证 → 提交改动。

参考：[Shiny 官方模块文档](https://shiny.posit.co/r/articles/improve/modules)。
